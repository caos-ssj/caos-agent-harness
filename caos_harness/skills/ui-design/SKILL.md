# UI & Frontend Design

## Visual Hierarchy and Layout
1. Keep the initial open state within a clean single-screen budget: avoid permanent multi-paragraph tutorials on operational views.
2. Collapse secondary tables, diagnostics and historical records inside labeled accordions with counts.
3. Preserve crisp contrast across backgrounds, borders, primary text and semantic status pills (success, warning, error, neutral).

## Interaction and Verification
- Provide keyboard navigation (`j`/`k`, `Esc`, `Enter`) on dense lists and modals.
- Verify mobile (`390px`), laptop (`1024px`) and desktop (`1440px`) breakpoints with zero unintended horizontal overflow.
- Check accessibility labels, focus outlines and empty/loading/error states on every view.
