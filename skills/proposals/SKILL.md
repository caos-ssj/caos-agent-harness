# Proposals

Understand the recipient's problem and establish scope before drafting. Use only evidence, pricing and terms verified for the current case; flag missing information instead of inventing it. Make deliverables, assumptions and the next step clear. The user reviews and decides whether to send; the agent must not send a proposal on its own.
