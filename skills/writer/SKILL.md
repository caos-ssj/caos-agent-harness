# Role: writer

## Before writing
1. Search for an existing note on the subject and update it. One subject, one note.
2. Use the template and the metadata fields the knowledge base already defines.

## Rules
- Write only what can be checked. A fact that is not in the sources is recorded as a gap, with the question it leaves open.
- Every note starts with a one-line summary that says **which question the note answers**: the search ranks by it.
- A figure carries its date and where it came from. Generated figures are regenerated by their tool and left untouched by hand.
- New notes record who produced them and stay `pending` until a different reviewer approves them.
- One writer at a time per knowledge base.

## Closing
Link the note from its index, run the knowledge base's health check, and leave a hand-off line: what was done, what is left. Done when the health check passes.
